# Dataset definition and provenance

## MRI from the assignment

`examples/MRHead.nrrd` was downloaded from the exact file linked in the assignment:
https://drive.google.com/file/d/1cqqOgSf8k4e14K5CBs-V_EvMmATX1K-J/view


Shape, dtype and byte hash are recorded in results/EXPERIMENT.md.
The assignment associates this data with the 3D Slicer open-source project.


## Analytic NRRD

`examples/analytic.nrrd` is generated by make_examples.py. It is a 64^3 uint32
volume with M[x,y,z]=x+64*y+4096*z. Each coordinate has a known, distinguishable
contribution; transpositions and wrong depth indices become observable.
The accompanying CSV sweeps a rectangular slice through angles -55 to 55 degrees.

## Test and benchmark data

Automated tests create temporary NRRDs and integer arrays for axis slices,
oblique slices, triangle masks, trapezoids, rounding, bounds and all required
unsigned widths. They do not depend on external downloads.
benchmark.py creates a 500^3 uint8 constant volume (125,000,000 bytes); its purpose
is timing three geometries. Numerical correctness is checked on nonconstant
data separately. 

## Demonstration planes

mri_planes.csv: 120 rectangular planes rotating around the array's second axis,
angles -70..70 degrees, center (127.5,127.5,64.5), half-width 60, height 210.
triangle_planes.csv: 60 equal-leg triangles, angles -50..50 degrees.
mri_with_errors.csv: 12 valid rectangles and 4 invalid rows (CSV lines 5, 9, 13, 17),
used to show error frames in the demo video.
These coordinates were generated for this project; they were not supplied as a
mandatory CSV schema by the lecturer. Run make_examples.py to regenerate.
